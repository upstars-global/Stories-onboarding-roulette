# Документація Poker Stories

## Загальний опис

Poker Stories — онбординг-сторіс, яка пояснює гравцеві суть покеру (Casino Hold'em) і показує хід гри: від ставки Ante до виплати. Сторіс складається з 7 слайдів, доступна 6 мовами та відкривається на сайті в iframe.

Кожен слайд — це відео на весь кадр і текст поверх нього: назва сторіс, рядок розділу, заголовок, опис і кнопка «Play Poker». Текст друкується одночасно з відтворенням відео; слайд завершується разом із відео, після чого відкривається наступний.

Проєкт побудований на Vue 3 + Vite. Результат збірки — статичні файли, які розміщуються на CDN.

## Посилання та вбудовування

### Адреса

Сторіс розміщується за тією ж схемою, що й попередні (roulette, blackjack, baccarat, game-shows):

```
https://cdn-wl.s3.amazonaws.com/common/stories/poker/index.html
```

### Приклад повного посилання

```
https://cdn-wl.s3.amazonaws.com/common/stories/poker/index.html?user_language=en&game_link=live%2Fcategories%2Fpoker&end_link=live%2Fcategories%2Fpoker
```

### Вбудовування в iframe

```html
<iframe
  src="https://cdn-wl.s3.amazonaws.com/common/stories/poker/index.html?user_language=en&game_link=live%2Fcategories%2Fpoker"
  width="100%"
  height="100%"
  allow="autoplay"
></iframe>
```

Відео запускається автоматично без звуку. Звук вмикає користувач кнопкою в шапці сторіс.

## Query параметри

Сторіс отримує параметри від батьківського сайту через URL.

| Параметр | Тип | Опис | Приклад |
|----------|-----|------|---------|
| `user_language` | String | Мова текстів: `en`, `de`, `fr`, `it`, `es`, `pt`. Значення передається малими літерами. Якщо параметр відсутній або мова не підтримується, використовується `en` | `user_language=de` |
| `game_link` | String | Посилання, на яке веде кнопка «Play Poker». Якщо параметр відсутній, використовується `live/categories/poker` | `game_link=live%2Fcategories%2Fpoker` |
| `end_link` | String | Посилання для переходу після закриття сторіс. Якщо параметр відсутній, після закриття перехід не виконується | `end_link=live%2Fcategories%2Fpoker` |

До `end_link` автоматично додаються UTM-мітки:

```
utm_source=site&utm_medium=story&utm_campaign=poker_story
```

Параметри `story`, `user_currency`, `stories_total` і `discover_link` приймаються, але на показ цієї сторіс не впливають: сторіс завжди починається з першого слайда, суми в текстах наведено в EUR, рядка з додатковим посиланням під кнопкою немає.

## Події для батьківського сайту

Сторіс надсилає події батьківському сайту через `window.parent.postMessage(message, '*')`. Кожна подія — текстовий рядок.

### Навігаційні події

| Подія | Коли відправляється |
|-------|---------------------|
| `click_forward` | Перехід на наступний слайд: тап у правій половині екрана, кнопка-стрілка на десктопі або автоматичний перехід після завершення відео |
| `click_backward` | Перехід на попередній слайд: тап у лівій половині екрана або кнопка-стрілка на десктопі |

### Контрольні події

| Подія | Коли відправляється |
|-------|---------------------|
| `click_pause` | Пауза: утримання пальця на екрані довше 350 мс, кнопка паузи на десктопі, поява попередження про горизонтальну орієнтацію |
| `click_play` | Відтворення відновлено після паузи або розпочато кнопкою Play, якщо браузер заблокував автозапуск |
| `mute_video` | Звук вимкнено |
| `unmute_video` | Звук увімкнено |

### Події закриття та переходів

| Подія | Коли відправляється |
|-------|---------------------|
| `close` | Натиснуто кнопку закриття |
| `start_game_btn` | Натиснуто кнопку «Play Poker» |
| `go_to_link:[URL]` | Через 300 мс після `close` — з адресою `end_link` та UTM-мітками (лише якщо `end_link` передано); через 300 мс після `start_game_btn` — з адресою `game_link` |

### Аналітичні події

| Подія | Коли відправляється |
|-------|---------------------|
| `opened_story:1` | Відкрито останній, сьомий слайд |

### Обробка подій у батьківському застосунку

```javascript
window.addEventListener('message', function (event) {
  if (typeof event.data !== 'string') return;

  if (event.data === 'close') {
    // закрити iframe зі сторіс
  } else if (event.data === 'start_game_btn') {
    // гравець натиснув «Play Poker»
  } else if (event.data.startsWith('go_to_link:')) {
    const url = event.data.replace('go_to_link:', '');
    // виконати перехід за url
  }
});
```

## Структура сторіз

### Слайди

| № | Рядок розділу | Заголовок | Зміст відео | Тривалість |
|---|---------------|-----------|-------------|------------|
| 1 | About game | What is Poker | Дилер за столом | 21,3 с |
| 2 | Poker hand ranking | Card combinations | Десять комбінацій від Royal flush до High card | 44,2 с |
| 3 | Game start | First move | Ставка Ante | 7,1 с |
| 4 | Game start | The deal | Роздача: карти гравця, карти дилера, флоп | 9,3 с |
| 5 | Call or Fold | Your decision | Вибір Call і ставка Play | 10,4 с |
| 6 | Winning combination | Final hand | Відкриття карт і виграш | 21,7 с |
| 7 | Payouts | How payouts work | Таблиця виплати | 13,5 с |

На слайді 4 опис з'являється трьома реченнями, кожне — у момент, коли на столі з'являються відповідні карти.

Загальна тривалість — 127 секунд. Угорі екрана показано 7 смужок прогресу, по одній на слайд.

### Мультимовність

Підтримувані мови:

- **en** — англійська (за замовчуванням)
- **de** — німецька
- **fr** — французька
- **it** — італійська
- **es** — іспанська
- **pt** — португальська

Відео однакове для всіх мов: написи всередині відео не перекладаються. Тексти слайдів зберігаються у файлі `src/data/stories.json`.

## Відео

### Формати

Кожне відео підготовлено в чотирьох форматах. Браузер отримує всі чотири джерела та відтворює перше, яке підтримує.

| Порядок | Формат | Файл | Тип джерела |
|---------|--------|------|-------------|
| 1 | AV1 | `story_N-av1.mp4` | `video/mp4; codecs="av01.0.08M.08, mp4a.40.2"` |
| 2 | H.265 | `story_N-h265.mp4` | `video/mp4; codecs="hvc1.1.6.L120.90, mp4a.40.2"` |
| 3 | H.264 | `story_N-h264.mp4` | `video/mp4; codecs="avc1.640028, mp4a.40.2"` |
| 4 | WebM (VP9) | `story_N.webm` | `video/webm; codecs="vp09.00.40.08, opus"` |

AV1 пропонується лише пристроям з апаратним декодуванням цього формату; решта пристроїв починає з H.265.

Параметри всіх файлів: 1080×1920, 30 кадрів за секунду, зі звуковою доріжкою.

### Розмір файлів, МБ

| Слайд | AV1 | H.265 | H.264 | WebM |
|-------|-----|-------|-------|------|
| 1 | 2,88 | 2,76 | 4,79 | 4,83 |
| 2 | 2,99 | 3,66 | 4,97 | 4,07 |
| 3 | 0,33 | 0,53 | 0,67 | 0,44 |
| 4 | 0,35 | 0,73 | 0,74 | 0,44 |
| 5 | 0,60 | 0,78 | 1,13 | 0,80 |
| 6 | 1,07 | 1,41 | 2,10 | 1,34 |

Користувач завантажує файли лише одного формату. Наступне відео починає завантажуватися заздалегідь, поки відтворюється поточне.

## Технічні деталі

### Управління

- **Мобільні пристрої**: тап у правій або лівій половині екрана — наступний або попередній слайд; утримання — пауза.
- **Десктоп**: кнопки-стрілки, кнопка паузи.
- **Звук**: кнопка в шапці сторіс; за замовчуванням звук вимкнено.

### Адаптивність

- Екран зі співвідношенням сторін 9:16 і десктоп: кадр відповідає макету.
- Екран, вищий за 9:16: відео займає всю ширину і притиснуте до нижнього краю, над ним — фон кольору верхнього краю відео; боки відео не обрізаються.
- Екран, нижчий за 9:16: відео займає всю ширину, зверху і знизу обрізається порівну.
- У горизонтальній орієнтації на мобільному пристрої показується прохання повернути телефон, відтворення ставиться на паузу.

## Розміщення на CDN

На CDN розміщується вміст папки `dist/` без змін: `index.html` і папка `assets/` з 28 відеофайлами, скриптом і стилями.

Вимоги до роздачі файлів:

- `Content-Type: video/mp4` для файлів `.mp4` і `video/webm` для файлів `.webm`;
- підтримка часткових запитів (`Accept-Ranges: bytes`).

## Перевірка

- Сторіс відкривається за посиланням із `user_language` для кожної з 6 мов; тексти відповідають мові.
- Відео запускається автоматично без звуку; кнопка звуку вмикає і вимикає звук.
- Слайди перемикаються тапом, стрілками та автоматично після завершення відео; смужки прогресу заповнюються.
- На слайді 4 речення опису з'являються разом із картами.
- Кнопка «Play Poker» надсилає `start_game_btn` і `go_to_link` з адресою `game_link`.
- Кнопка закриття надсилає `close` і, якщо передано `end_link`, `go_to_link` з адресою та UTM-мітками.
- На останньому слайді надсилається `opened_story:1`.
